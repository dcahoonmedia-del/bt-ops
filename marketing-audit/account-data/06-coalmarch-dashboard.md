## What Coalmarch calls a “lead”

From dashboard modules + mail, a lead is a **tracked call, webform, or message** attributed to a channel.  

**Unknown / not shown in UI notes:**

- Deduping calls vs forms from the same person  
- Repeat callers as new leads  
- Existing customers  
- Spam  
- Minimum duration  
- First- vs last-touch  

Treat CPL as **cost per platform lead**, not cost per booked job.
