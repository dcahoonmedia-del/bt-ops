### IMPORTANT NOTES

1. **Report Type:** This report shows "Service Volume" which appears to track **active service lines with Annual Value and Total Value**, NOT necessarily completed work orders.
2. **Quantity Meaning:** The "Quantity" column represents active service lines/subscriptions for each service type within the date range. This is NOT the same as completed work order count.
3. **Status:** No status filter (completed/canceled/incomplete) visible in this report. Would need different report for completion status.
4. **New vs Existing Customer:** UNAVAILABLE - This report does not distinguish between new customer acquisitions vs. existing customer services. Would require customer-level analysis or different report structure.

### DATA QUALITY ISSUES

1. **"Service Volume" ≠ "Work Order Count"**
   - The report used shows active service lines/subscriptions, NOT completed WOs
   - Cannot confirm if these are scheduled, completed, or canceled
   - Annual Value suggests these are recurring service contracts, not one-time inspections

2. **Missing Status Information**
   - No completed/canceled/incomplete breakdown available in this report type
   - Would need "Completed Work Orders" report with status filters

3. **Cannot Distinguish New vs Existing Customers**
   - Report does not show customer creation date
   - Cannot determine if inspection was for new customer vs existing
   - Would require customer-level analysis or different report
   - **USER INSTRUCTED: Do NOT label any row as "new customers"**

4. **Conversion Rate: UNAVAILABLE**
   - Cannot track which inspections converted to ongoing service
   - Would need customer journey analysis (inspection WO → first recurring service WO)
   - Requires either custom report or data export

5. **Channel Attribution: UNAVAILABLE**
   - Service type names don't indicate if booking came from realtor, direct, or other channel
   - Would need custom field for lead source or campaign tracking
